## 📖 O que é este projeto?

Este é o **portfólio profissional** de **Matheus Gustavo da Silva Pires**, um site pessoal desenvolvido para apresentar sua trajetória, projetos, habilidades técnicas e experiências profissionais nas áreas de:

- 📊 **Análise de Dados & Business Intelligence (BI)**
- 💻 **Engenharia de Software**
- 🗄️ **Bancos de Dados & SQL**

O site foi construído com **HTML, CSS e JavaScript puro**, sem dependências de frameworks, com uma identidade visual moderna no estilo **dark/tech** e acento em azul ciano (`#38bdf8`).

---

## ✨ Funcionalidades

| 🧩 Recurso | 📝 Descrição |
|-----------|-------------|
| 🎯 **Hero animado** | Efeito *typewriter* com frases alternando entre português e inglês |
| 📅 **Idade dinâmica** | Cálculo automático da idade com base na data de nascimento |
| 🖼️ **Projetos em destaque** | Cards com badges de destaque ("📌 Destaque BI" e "📌 Destaque Dev") |
| 🗂️ **Filtros por categoria** | Filtragem entre *Todos*, *Dados & BI* e *Desenvolvimento Web* |
| 🃏 **Sistema de abas** | Navegação por abas dentro de cada projeto (Visão Geral, Detalhamento, Modelagem, Links) |
| 🎠 **Carrossel de imagens** | Carrossel com setas e indicadores para visualizar os detalhes dos projetos |
| 📚 **Formação com progresso** | Barra de progresso automática do curso de Engenharia de Software |
| 📱 **Menu responsivo** | Menu hambúrguer funcional para dispositivos móveis |
| ⬆️ **Voltar ao topo** | Botão de rolagem suave para o topo da página |

## 🚀 Como executar localmente

É super simples! Como o projeto é 100% estático (sem build ou instalação de dependências):

```bash
# 1. Clone o repositório
git clone https://github.com/MatheusPiresDEV/Port.git

# 2. Acesse a pasta do projeto
cd Port

# 3. Abra o index.html no seu navegador
start index.html
```

Ou, se preferir, basta abrir o arquivo `index.html` com um duplo clique. Também é possível usar uma extensão como o **Live Server** no VS Code para uma experiência com recarregamento automático.
